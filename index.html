Covariance Matrix

See what covariance actually means, manipulate the data, and watch the matrix change in real time.

1 · The big idea

Covariance asks: “Do these features move together?”

Suppose each dot is one observation with two features, X and Y.

  • Positive covariance: X goes up → Y tends to go up.
  • Negative covariance: X goes up → Y tends to go down.
  • Near zero: no strong linear relationship.
Important: covariance describes a linear relationship. Zero covariance does not necessarily mean the variables are completely unrelated.
2 · Build the matrix

Every feature gets a row and a column

For two features, the covariance matrix is:

Var(X)
Cov(X,Y)
Cov(Y,X)
Var(Y)

The diagonal contains each feature's variance. The off-diagonal contains how the two features vary together.

Σ = [ Var(X)   Cov(X,Y) ;   Cov(Y,X)   Var(Y) ]
Notice: Cov(X,Y) = Cov(Y,X), so a covariance matrix is symmetric.

4 · Why ML cares

Covariance reveals the shape of your data

Imagine plotting height and weight. If taller people tend to weigh more, the cloud of points stretches diagonally.

The covariance matrix captures that orientation mathematically.

In PCA: eigenvectors of the covariance matrix give the principal directions, while eigenvalues tell us how much variance lies along those directions.
5 · From 2 features to many

With n features, you get an n × n matrix

For three features X₁, X₂, and X₃:

Σ = ⎡ Var(X₁)   Cov(X₁,X₂)   Cov(X₁,X₃) ⎤
    ⎢ Cov(X₂,X₁)   Var(X₂)   Cov(X₂,X₃) ⎥
    ⎣ Cov(X₃,X₁)   Cov(X₃,X₂)   Var(X₃) ⎦

So with 5 features, your covariance matrix is 5 × 5. Every cell answers a question about a pair of features.

6 · Check yourself

Quick quiz

Question: If two features have a large negative covariance, what generally happens?

When one feature increases, the other tends to decrease. Their relationship slopes downward.
Remember this

Covariance matrix → PCA

Variance tells you how much one feature spreads out. Covariance tells you how two features move together. Put all of those values together, and you get the covariance matrix.

For advanced ML: covariance matrix → eigenvectors/eigenvalues → PCA → principal directions of variation.
